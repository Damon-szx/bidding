## 本次范围

不改变多 Agent 分工、核验条件、下载队列和文件校验。不新增模型调用或向量数据库，不迁移数据库，不改历史日志。

采集器在现有提取正文上生成 `content_version`、`content_blocks`、`content_directory`。按真实 HTML 标题、编号段落、行边界及长度分块，单块最多 900 字符；不按关键词判断行业、资格或文件可用性。每块保留原文精确 start/end 和 text，拼接可还原保存的正文。块版本绑定来源网址、正文、标题分区和分块算法；浏览器渲染或裁剪正文后重新建立索引。采集超过原有 60000 字符上限时明确标记不完整。

长详情（超过 1600 字符）首次只返回目录、关键字段、附件与获取入口。目录标题是定位线索，不是完整核验证据。目录预算不足时标记不完整，可分页读取。短详情保留完整正文直读；列表继续返回条目和分页入口，不增加按块读取要求。最终预览预算计算包含状态和提示文字。

原有 `read_tool_result` 增加可选 `block_id`，不增加独立工具。传同一来源 `log_id` 与目录 `block_id`，offset/limit 对应块内字符。读取返回原文、块版本及原始正文坐标。旧日志在内存建立索引，不修改数据库。字段、关键词、分页、访问权限及已读范围复用继续有效。块 ID 不作为浏览器按钮或页面 ID。仍使用原文引文核验，本次不改核验证据协议。

## 使用及回退

`.env` 中 `PAGE_CONTENT_MODE=blocks` 启用长详情目录预览（默认）。设为 `legacy` 恢复正文开头预览，原始字段读取一直可用。重启本机服务后配置与代码完整生效。本次开发没有重启正在运行的服务，也未自动重放真实联网下载。

完整代码回退可以在工作区干净且没有任务运行时切换到 `main` 或基线标签，再重启服务。功能分支可用 `git diff main...feat/page-content-blocks` 审查。切换版本不会删除业务数据，但重启会使内存浏览器动作失效，旧任务需重新获取页面入口。

## 离线对比

可复现命令（在项目根目录运行）：

```sh
.venv/bin/python scripts/compare_page_previews.py
.venv/bin/python scripts/compare_page_previews.py --tools-json /path/to/local-tools.json
.venv/bin/pytest -q
```

对比脚本从基线标签直接读取旧预览函数，在同一批页面数据上比较新旧首次预览，不切换工作区、不调用模型、不访问网站，也不复制业务日志到仓库。必须区分本地保守 Token 估算、供应商实际用量和端到端耗时。

真实对照请求记录为 budget_exceeded，48 条工具记录、58 次模型调用，供应商累计输入 602074、输出 16233 Token。正文样本包括 2126 字符列表、428 字符详情及 93 字符未识别页面；详情很短，主要问题并非长正文。本次短详情首次预览估算保持不变，列表及未识别页因修正最终预算计量约减少 6%–11%，不能据此宣称整轮 Token 或模型调用次数明显下降。

合成的 2471 字符、多章节长公告：首次预览估算从 1923 降到 998，约减少 48%。这只衡量首次预览；后续取证仍有输入成本，收益取决于相关段落覆盖情况，不能作为实际业务加速比例。

测试覆盖原文精确还原、版本变更、HTML 标题、完整性标记、历史日志兼容、跨任务访问拒绝、错页块 ID 拒绝、分页与已读区间复用、主 Agent 实际工具路由、预览预算以及 legacy 回退。

本次验证结果：基线 273 项测试通过；功能分支 284 项通过、12 项因外部环境条件跳过。另外显式启用 Chrome，验证“渲染后正文分块”和“网站弹窗及下载拒绝错误保留”，两项均通过。没有调用真实模型或重跑真实下载任务。GitHub 远端尚未同步，需明确上传授权及有效本机认证后再推送。
